# sold forums

the school forum app sold.

## download (stable build)
https://github.com/gamerbemnet/sold-forums/releases/latest/download/soldtherealone.apk

## open in browser
- https://soldlaunch.pages.dev - launcher hub (all mirrors + app download)
- https://sold2.soldforums.workers.dev - the forum

## installing
1. open the apk - Chrome warns it is not from a store: choose keep / download anyway
2. when Play Protect says unknown app: tap Install anyway
3. open - it loads the forum and you log in as usual
